Who is Deal Strategy Coach not ideal for?

  • Anyone who cannot give the required inputs (Deal name, Deal stage); the answer is built only from them.
  • Teams that want the tools to read their CRM, email or call notes: they work only from what you type.
  • Sending anything straight to a buyer: every output is a draft for a person to review first.

How do I use Deal Strategy Coach from Claude?

Connect Revenue Enablement once (see Connect), then ask in plain words. A prompt built from the tested example:

Use Revenue Enablement's Deal Strategy Coach tool. deal name: Example Clinic Group expansion; deal stage: demo; deal value: 45000; champion status: potential champion; days in stage: 20.

MCP tool name: deal_strategy_coach. REST: POST https://revenue-enablement.gtmhelix.com/api/tools/deal_strategy_coach with this JSON body (see Docs):

{
  "input": {
    "deal_name": "Example Clinic Group expansion",
    "deal_stage": "demo",
    "deal_value": 45000,
    "champion_status": "potential_champion",
    "days_in_stage": 20
  }
}

How does Deal Strategy Coach work?

It applies fixed rules in the Revenue Enablement code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server call the same tool code, so the same input gives the same answer in both.
