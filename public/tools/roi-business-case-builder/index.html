How do I use ROI Business Case Builder from Claude?

Connect Revenue Enablement once (see Connect), then ask in plain words. A prompt built from the tested example:

Use Revenue Enablement's ROI Business Case Builder tool. your solution: ClinicFlow scheduling; primary value driver: cost reduction; company size: mid market; annual revenue: 20000000; employee count: 400; solution price: 30000.

MCP tool name: roi_business_case_builder. REST: POST https://revenue-enablement.gtmhelix.com/api/tools/roi_business_case_builder (see Docs).

How does ROI Business Case Builder work?

It applies fixed rules in the Revenue Enablement code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
