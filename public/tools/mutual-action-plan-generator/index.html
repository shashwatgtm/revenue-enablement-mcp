Who is Mutual Action Plan Generator not ideal for?

  • Anyone who cannot give the required inputs (Deal name, Target close date); the answer is built only from them.
  • Teams that want the tools to read their CRM, email or call notes: they work only from what you type.
  • Sending anything straight to a buyer: every output is a draft for a person to review first.

How do I use Mutual Action Plan Generator from Claude?

Connect Revenue Enablement once (see Connect), then ask in plain words. A prompt built from the tested example:

Use Revenue Enablement's Mutual Action Plan Generator tool. deal name: Example Clinic Group expansion; target close date: 2026-12-15; current stage: evaluation.

MCP tool name: mutual_action_plan_generator. REST: POST https://revenue-enablement.gtmhelix.com/api/tools/mutual_action_plan_generator with this JSON body (see Docs):

{
  "input": {
    "deal_name": "Example Clinic Group expansion",
    "target_close_date": "2026-12-15",
    "current_stage": "evaluation"
  }
}

How does Mutual Action Plan Generator work?

It applies fixed rules in the Revenue Enablement code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server call the same tool code, so the same input gives the same answer in both.
