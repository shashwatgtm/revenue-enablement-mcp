Demo Script

Part 1: Opening (4 minutes)

[0:00] Introduction

"Thanks everyone for joining. I'm [Your name] and I'll be walking you through ExampleCo Scheduler today.

Before I share my screen, I want to make sure we cover what's most important to you. [Turn to primary audience]: What would make this 30 minutes valuable for you?"

[Wait for response - this shapes your demo]

[1:00] Agenda Setting

"Perfect. Here's my plan for today:

  1. Quick validation of what I've learned about your situation
  2. Show you how ExampleCo Scheduler addresses those specific needs
  3. Leave time for questions and discussion
  4. Agree on next steps

Does that work for everyone?"

Part 2: Discovery Confirmation (4 minutes)

[4:00] Validate Understanding

"Before I show you anything, let me confirm what I've learned to make sure the demo is relevant:

Based on what [champion] shared, it sounds like you're dealing with [pain points].

Did I capture that correctly? What would you add?"

[Listen and adjust demo focus based on responses]

Discovery Questions to Ask:

  • "What's driving your interest in looking at solutions like this?"
  • "What does success look like for you?"
  • "Who else needs to be involved in this decision?"
Part 3: Solution Demo (16 minutes)

[8:00] Transition to Demo

"Great, that confirms what I thought. Let me show you how ExampleCo Scheduler addresses exactly those challenges. I'm going to share my screen..."

[Share screen with demo environment]

Demo Flow

Feature 1: [Address Pain Point 1]

Setup:

"You mentioned [pain point]. Let me show you how we handle that..."

Action:

[Show the feature]

Value Statement:

"What this means for you is [business outcome]. [Customer example] saw [specific result] using this."

Check-in:

"How does this compare to how you're doing it today?"

Feature 2: [Address Pain Point 2]

Setup:

"Another thing you mentioned was [pain point]..."

Action:

[Show the feature]

Value Statement:

"This is typically where we see the biggest time/cost savings because [reason]." (Example claim: keep it only if your customer results support it)

Check-in:

"Does this address what you were looking for?"

Feature 3: [Differentiator]

Setup:

"This next part is what really sets us apart..."

Action:

[Show unique capability]

Value Statement:

"This is something our customers tell us they can't find elsewhere." (Example claim: keep it only if customers have told you this)

Part 4: Discussion (4 minutes)

[24:00] Open for Questions

"Let me stop sharing for a moment. What questions do you have about what you've seen?"

Common Objections to Prepare For:

"How long does implementation take?"

"Typically [timeframe]. Our methodology includes [your implementation steps]..."

"What about integration with [system]?"

"We have pre-built integrations with [systems]. Let me show you..."

"What does pricing look like?"

"I'd like to understand your needs better to give you accurate pricing. Generally..."

"We need to think about it."

"Absolutely. What specific aspects do you want to think through? Maybe I can help."

Part 5: Close (2 minutes)

[28:00] Summarize & Close

"Before we wrap up, let me summarize what we covered:

  1. [Pain point 1] → ExampleCo Scheduler addresses this with [feature]
  2. [Pain point 2] → You'd get [outcome]
  3. [Pain point 3] → This would help you [result]

The Ask:

"Based on what you've seen, what would be helpful as a next step?

Options might be:

  • Technical deep dive with your team
  • Business case review
  • Reference call with similar customer
  • Pilot/POC discussion

What makes sense for you?"

If Positive:

"Great! I'll send a follow-up with [materials] and a calendar invite for [next step]. Who else should I include?"

If Hesitant:

"What concerns do you still have? I want to make sure you have everything you need."

Post-Demo Checklist

  • [ ] Send follow-up email within 2 hours
  • [ ] Include demo recording (if recorded)
  • [ ] Send resources promised
  • [ ] Update CRM with notes
  • [ ] Schedule next meeting
  • [ ] Brief champion separately

Demo Tips

Do:

  • Lead with outcomes, not features
  • Ask questions throughout
  • Personalize examples
  • Confirm understanding frequently
  • Leave time for questions

Don't:

  • Show everything you can do
  • Talk more than listen
  • Ignore attendee body language
  • Avoid tough questions
  • Leave without clear next steps

Who is Demo Script Builder not ideal for?

  • Anyone who cannot give the inputs listed above; the answer is built only from them.
  • Teams that want the tools to read their CRM, email or call notes: they work only from what you type.
  • Sending anything straight to a buyer: every output is a draft for a person to review first.

How do I use Demo Script Builder from Claude?

Add Revenue Enablement once (see Use it in Claude or ChatGPT), then ask in plain words. A prompt built from the tested example:

Use Revenue Enablement's Demo Script Builder tool. demo type: First look; your solution: ExampleCo Scheduler; demo duration: 30; primary audience: Operations Director; customer industry: Healthcare.

How does Demo Script Builder work?

No sign-in. A web browser is enough, and the answer comes back in a second or two.

  1. Fill in the form above, or press Fill in an example.
  2. Press Run Demo Script Builder.
  3. Read the result on this page, then copy it and edit it before you use it.

It applies fixed rules in the Revenue Enablement code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the AI assistant connector run the same tool code, so the same input gives the same answer in both.
