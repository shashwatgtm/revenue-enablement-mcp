How do I use Champion Enablement Kit from Claude?

Connect Revenue Enablement once (see Connect), then ask in plain words. A prompt built from the tested example:

Use Revenue Enablement's Champion Enablement Kit tool. asset type: executive brief; your solution: ClinicFlow scheduling.

MCP tool name: champion_enablement_kit. REST: POST https://revenue-enablement.gtmhelix.com/api/tools/champion_enablement_kit (see Docs).

How does Champion Enablement Kit work?

It applies fixed rules in the Revenue Enablement code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
